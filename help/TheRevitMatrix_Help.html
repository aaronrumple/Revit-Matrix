Getting started

Install: run TheRevitMatrix-version-x64.msi. It installs to C:\Program Files\PyPiPie\The Revit Matrix and adds Start menu › PyPiPie › The Revit Matrix. Installing a newer version replaces the old one; uninstall from Settings › Apps.

The installer is not code-signed. Windows SmartScreen shows Windows protected your PC: click More info, then Run anyway. The install prompt shows Publisher: Unknown. Download it only from the Releases page, where each release lists its SHA-256 checksum.

Start The Revit Matrix, then start Revit (or the other way round). Within a few seconds it finds the running Revit session and attaches to its journal file. Everything Revit writes to the journal from then on appears in the output window as it happens.

Revit records every session in a journal: the commands you run, dialogs and their answers, add-ins loading, warnings and errors, and timing and memory figures. The Revit Matrix lets you read it live instead of digging through the file after a crash.

It only reads the journal. Revit is never slowed down or blocked, and nothing is written to Revit or the journal.

The window

The title bar shows the journal being watched and the Revit process ID. The ? button beside minimize opens this help (or press F1).

RowWhat it holds
Session tabsA tab for each Revit session and opened journal, then Refresh, Open journal file… and the Theme button.

Status barCredit, status messages, the session state and the version. Its color shows what the session is doing.

Right-click menu: right-click anywhere in the window to open or close the panels. Pick Timeline, Slow operations, Add-in startup, Session summary or Journal folders to open the bottom panel on that tab (a check mark shows the one that's open; pick it again to close the panel), or Revit performance to show or hide the side panel. Over the log, the menu also has Bookmark line for the line you clicked, Copy and Select all.

Sessions & journals

Every 3 seconds the app lists the running Revit.exe processes and matches each one to the journal it created when it started, in %LOCALAPPDATA%\Autodesk\Revit\Autodesk Revit 20XX\Journals. Several sessions, of the same or different Revit versions, each get their own journal.

  • A tab per session: each running Revit gets its own tab, named by version and open model (for example Revit 2026 · Tower.rvt). A new Revit gets a tab as soon as it starts. Hover a tab for its process ID, start time and journal path.
  • Everything per tab: each tab keeps its own log, category counts, timeline, slow operations, add-in report, summary, bookmarks and performance graphs. Switching tabs is instant.
  • Background tabs keep reading: a tab that isn't in front still reads its journal. Its name turns bold when it has new lines, and a red number shows how many errors it has logged. Notifications for errors and long opens, saves and syncs come from background tabs too, even while the app is in front.
  • Tab dot: green while that Revit is running, gray after it closes (the tab stays so you can read the end of the journal), blue for a journal opened from a file.
  • Closing tabs: click × on a tab or middle-click it. A closed session's tab doesn't come back on its own; Refresh reopens tabs for every running session.
  • Open journal file…: opens any journal in its own tab, including one from an earlier session or a redirected journal folder. Opening a journal that already has a tab switches to it.
  • Clear empties only the tab in front.
  • Load existing: when on, a new tab shows the last 2 MB of the journal first; when off, only new lines appear.
Sessions are matched by start time. If a journal is created at almost the same moment as another Revit launch, it can be matched to the wrong session; use Open journal file… to pick it directly.

Reading the journal

A journal is a VBScript that can replay the session. Lines that don't start with ' are the replay script; lines starting with ' are comments and diagnostics. Each kind gets its own color (dark-theme colors shown):

ColorJournal content
Gold, boldJrn.Command: commands you ran from the ribbon, menus or shortcuts.
Light blueOther Jrn.* replay lines (mouse, buttons, dialogs, data) and their argument lines.
Orange"quoted" values in replay lines.
Slate'C, 'E and 'H timestamps.
Teal->enter / <-exit markers and ' [Jrn.*] data lines such as add-in manifests.
GrayOther comments and diagnostics.
GreenAPI_SUCCESS add-in messages.
AmberWarnings.
Red, boldAPI_ERROR, errors, exceptions, failures and crashes.
Dim italicMemory (Delta VM), GDI usage and performance tables.
PurpleThe header: build, branch, release.

Untick Colors to show plain text.

Category filters

The Show row has one chip per category, each with its color dot and a live count of lines.

  • Click a chip to show or hide that category.
  • Right-click a chip to show only that category.
  • All shows every category. Problems shows errors and warnings only. Activity shows commands, actions, events, timing and problems, without add-in and memory noise.

Memory stats start hidden, because they are a large share of most journals. The text filter combines with the chips: a line must pass both to be shown.

Line numbers & time

The gutter left of the output shows two columns, each switched on or off with the Line # and Time options.

  • Line # is the line's number in the journal file, not its position in the view, so it stays right when you filter. Lines the app adds itself (such as session ended) have no number.
  • Time is shown as HH:mm:ss::hh (hours, minutes, seconds, hundredths), taken from the journal itself.
    • Bright: the line has its own 'C/'E/'H timestamp.
    • Dim: the line has none, so it shows the last timestamp before it.

Save… writes the lines currently shown, including whichever of these columns are on.

Timeline

Click the timeline button in the title bar (dots on lines, left of the chart button) or press F3 to slide out the panel along the bottom of the window. Its tabs are Timeline, Slow operations, Add-in startup, Summary and Journal folders; the panel reopens on the tab you used last.

The Timeline tab It plots every journal entry by time: one row per category, marked by a colored square in the category's color, and one dot per entry.

  • Hover a dot to see its category, line number, time and text. Hover a square to see the category's name.
  • Click a dot to jump to that line in the log; it is highlighted and the dot gets a ring. Lines in a hidden category can't be shown until you turn the category back on under Show.
  • Hidden categories stay on the timeline, faded, so you can still see when they happened.
  • Window shows the last 1, 5 or 15 minutes, or All of the journal. With Follow live on, the newest entries stay in view and a blue line marks the present.
  • Zoom and move: drag the handles of the Time range slider, or drag between them; press and hold the middle mouse button (the wheel) on the timeline and drag to slide it back and forth through time; the mouse wheel zooms in and out around the pointer, keeping the moment under the mouse in place; Shift + wheel also moves through time. Zooming or moving turns Follow live off; choosing a window turns it back on.

Entries without a timestamp of their own are placed at the last timestamp before them, the same time shown in the log's time column. When the performance panel is open too, it keeps the full height of the window and the bottom panel sits beside it, under the log.

Slow operations

Revit times every operation that takes more than about 0.1 second and writes how long it took to the journal. This tab lists them, slowest first: opens, saves, syncs with central, regenerations, view drawing, upgrades and the rest. It answers "why is Revit slow today?"

ColumnWhat it shows
StartedWhen the operation began (its end time in the journal, less its duration).
SecondsHow long it took.
KindOpen, Save, Sync, Regenerate, View, Upgrade, Export, Transaction, Start/exit or Other, worked out from the operation's name.
Leveltop for an operation in its own right; dots for a step inside another one.
OperationRevit's name for it. "Waiting:" marks a stretch where Revit's window wasn't responding.
FileThe model or template, when Revit names one.

Click a column heading to sort by it (again to reverse). Click a row to jump to its line in the log. Turn on Include nested steps to also see the stages inside each operation, such as the loading steps of an open.

Add-in startup

Ranks the add-ins by how long they took to load when Revit started, with the memory each added (Revit's own figure). It is the place to start when Revit is slow to open, and useful to anyone managing a firm's add-ins.

Times are approximate. Revit only writes a timestamp now and then while add-ins load, so add-ins that loaded between the same two timestamps share one row; the slow one is among them. Startup is at the beginning of the journal: if this tab is empty, open the session's journal with Load existing on, or from the start with Open journal file….

Session summary

One page about the session: the Revit version, when it ran, files opened, saves and syncs with how long each took, commands run, errors and warnings, the slowest operations, add-in startup, and peak memory (Revit's own figure and Windows'). Copy puts it on the clipboard as plain text, ready for a support ticket; Save… writes it to a text file.

Journal folders

Revit never deletes its journals. This tab lists the journal folder of every Revit version on the PC (left) and the journal files in them (right). Drag the divider between the two lists left or right to resize them (double-click it to reset); the app remembers where you left it. Anything moved can be restored from the Recycle Bin.

  • Folders: how many journals each folder holds, their size, the oldest, and how many are older than the days you enter. Select one or more folders (Ctrl/Shift+click) to list only their journals; with none selected, every folder's journals are listed. Double-click a folder to open it in File Explorer.
  • Pick journals: click a journal, or Ctrl+click and Shift+click to select several (Ctrl+A selects all). Select old selects every listed journal older than the days entered. Click a column header to sort.
  • Move selected to Recycle Bin (or the Delete key) moves just the selected journals, after you confirm.
  • Move old to Recycle Bin moves every journal older than the days entered, in all folders.
  • In use: journals a running Revit has open, or that are open in a tab here, are marked and always kept.
  • Double-click a journal to open it in a tab.

Errors & bookmarks

  • F8 jumps to the next error or warning in the log, Shift+F8 to the previous one.
  • Ctrl+B bookmarks the line the cursor is on (or removes its bookmark); bookmarked lines get a blue bar in the gutter. F9 and Shift+F9 move between bookmarks.

Click a line in the log to put the cursor on it. Searching moves from the cursor, so only lines currently shown (not hidden by the filters) are found.

Notifications

With Notify on (in the toolbar), and while The Revit Matrix is in the background, Windows shows a notification when Revit logs an error (at most one every 30 seconds) and when an open, save or sync with central that took 10 seconds or more finishes. Click the notification to bring the app forward.

Performance panel

Click the chart button in the title bar, beside ?, or press F2 to slide out the performance panel on the right. It graphs the Revit session in the selected tab, sampled every second, over the last 5 minutes (each tab keeps its own history, so switching tabs shows that session's graphs at once):

GraphWhat it shows
CPURevit's share of all the PC's logical processors, as Task Manager shows it. Much of Revit runs on one core, so on an 8-core PC a busy single-threaded task reads about 12%.
Revit's own memory figureThe RAM in use that Revit itself writes to the journal (the Delta VM / RAM lines). It updates when Revit reports, so it moves in steps.
MemoryMemory Revit has committed (private bytes). The line under the panel title shows how much of it is in RAM right now.
GPUThe busiest graphics engine Revit is using, the same figure as Task Manager's GPU column.
GPU memoryDedicated video memory Revit is using.

Each graph shows the current value and the peak since the session was attached. Sampling starts when the app attaches to a running session, so the history is there when you open the panel. When Revit closes, the graphs keep its last minutes.

GPU figures need Windows 10 version 1709 or later and a WDDM 2 graphics driver; the panel says so when they aren't available. If Revit runs as administrator and this app doesn't, Windows hides Revit's CPU time; run The Revit Matrix as administrator to see it. A journal opened from a file has no running process to graph.

Themes

The Theme button cycles Auto, Dark and Light.

  • Auto follows the Windows app theme and switches when Windows does. Revit 2024 and later uses the same theme when its follow the system theme option is on.
  • Revit's own theme setting can only be read from inside Revit. If you've set Revit to a fixed theme, choose Dark or Light to match.

Tips & troubleshooting

  • Find what went wrong: click Problems, then switch All back on and use the line number to see what happened just before.
  • Follow your own work: click Activity to see the commands you run and the dialogs you answer.
  • A line appears late: Revit buffers some journal writes, so a line can appear a moment after the action.
  • No session found: the app looks only in your own journal folders. A journal redirected elsewhere can be opened with Open journal file….
  • Version shows only "Revit": Revit is running as administrator and this app isn't. Matching still works.

Files & settings

  • Settings (theme, hidden categories, gutter columns, performance panel, timeline) are saved in %APPDATA%\TheRevitMatrix\settings.json.
  • Journals are read from %LOCALAPPDATA%\Autodesk\Revit\Autodesk Revit 20XX\Journals, as Windows-1252 text.
  • This help is help\TheRevitMatrix_Help.html, next to the program.
  • Installed with the MSI, the program is in C:\Program Files\PyPiPie\The Revit Matrix.
