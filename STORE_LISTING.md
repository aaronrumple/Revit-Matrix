## Product name

The Revit Matrix

## Short description (up to 1,000 characters)

Watch Autodesk Revit's journal file live. The Revit Matrix finds every running Revit session and streams its journal into a colored, filterable log, with a timeline, slow-operation and add-in startup reports, a session summary and live CPU, memory and GPU graphs. A companion app for BIM managers, support staff and add-in developers.

## Description (up to 10,000 characters)

Revit writes a journal file for every session: every command you run, every dialog, every add-in message, every warning and error, and how long Revit took to open, save and sync. It's the first thing Autodesk support and BIM managers ask for when something goes wrong, but it's a long, cryptic text file that's hard to read while Revit is running.

The Revit Matrix reads those journals for you, live.

SEE WHAT REVIT IS DOING, AS IT HAPPENS
The Revit Matrix finds every running Revit session on your PC and matches each one to its own journal. Each session gets its own tab, and new lines appear the moment Revit writes them. Several sessions and Revit versions can run at once; tabs in the background keep reading, turn bold when they have new lines, and show how many errors their session has logged.

A JOURNAL YOU CAN ACTUALLY READ
- Every line is colored by kind: commands, replay actions, timestamps, comments, add-in messages, warnings, errors and memory statistics.
- A gutter shows each line's number in the journal file and its time.
- Category chips show or hide each kind of line, each with a live count, plus Problems and Activity presets.
- A text filter shows only the lines you're looking for.
- Press F8 to jump to the next error or warning; bookmark lines with Ctrl+B and move between them with F9.

TIMELINE
Slide out a timeline along the bottom of the window: every journal entry as a colored dot in its category's row, by time. Click a dot to jump to its line. Follow the session live, or zoom in with the mouse wheel and drag through time with the middle mouse button.

FIND OUT WHAT'S SLOW
- Slow operations: every operation Revit timed (opening, saving, syncing with central, regenerating, opening views) with how long it took. Sort by time and click to jump to the line.
- Add-in startup: which add-ins slowed Revit's startup, slowest first, with the memory each one added.
- Session summary: files opened, saves, syncs, commands, errors, warnings, the slowest operations and peak memory, as plain text ready to paste into a support ticket.

LIVE PERFORMANCE GRAPHS
Slide out a panel of live graphs for the Revit session in front: processor use, memory, Revit's own memory figure, GPU use and GPU memory, over the last five minutes, with current values and peaks. Each session tab keeps its own history.

NOTIFICATIONS
While you work in Revit, The Revit Matrix can show a Windows notification when Revit logs an error, or when an open, save or sync with central that took 10 seconds or more finishes.

TIDY UP OLD JOURNALS
Journal files can accumulate over time. The Journal folders tab shows each Revit version's journal folder and its size. Select specific journals or all journals older than a chosen number of days and move them to the Recycle Bin. Journals used by a running Revit session are kept.

MADE TO FIT IN
- Dark and light themes that follow Windows, and Revit when Revit follows the system theme.
- Right-click anywhere to open or close the panels.
- Save the log, with its line numbers and times, to a text file.
- Full help built in: press F1.

LOCAL, PRIVATE JOURNAL MONITORING
Live monitoring reads the journal while Revit is writing it, without blocking Revit or changing the active file. The Journal folders view can move journals you select to the Recycle Bin; journals in use by a running Revit session are kept. No Revit add-in or Autodesk account is needed. The app collects no personal data and sends nothing over the internet.

Free and open source under the GNU General Public License v3.0. Source code: https://github.com/aaronrumple/Revit-Matrix

REQUIREMENTS
- Autodesk Revit installed on the same PC for live session detection and monitoring. Supports Revit versions that write journals under %LOCALAPPDATA%\Autodesk\Revit\Autodesk Revit 20XX\Journals.
- Saved journal files can also be opened without a running Revit session.
- Windows 10 version 2004 (build 19041) or later, x64.

## Submission options: restricted capability

The package declares `runFullTrust`. Partner Center asks why. Suggested answer:

> The Revit Matrix is a WPF desktop app packaged with MSIX. It needs full trust to enumerate running Revit.exe processes, read their local journal files while Revit is writing them, and collect the process and system performance data shown in its graphs. The Journal folders view also lets users explicitly move selected old journals to the Recycle Bin; journals in use by a running Revit session are kept. The app does not modify active journals, collect personal data, or send journal contents over the internet.
